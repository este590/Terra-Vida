# Terra Vida — Proyecto Android

Aplicación educativa ambiental en español. Incluye guía de reciclaje, retos, puntos locales, seguimiento de participación, minijuego y sección de comunidad.

## Crear el APK desde GitHub (teléfono o computadora)

1. Crea un repositorio nuevo llamado `TerraVida`.
2. Sube **todo el contenido de esta carpeta**, no el archivo ZIP dentro del repositorio. Debes conservar la carpeta `.github/workflows`.
3. En GitHub abre **Actions** y selecciona **Crear APK Terra Vida**.
4. Pulsa **Run workflow** (o espera a que termine la compilación automática).
5. Abre la ejecución terminada y descarga el artefacto **TerraVida-APK**.
6. Extrae el ZIP descargado e instala `app-debug.apk` en tu Android.

## Nota
Esta es una primera versión funcional y educativa. Los puntos se guardan en el dispositivo; todavía no hay cuentas, sincronización en internet, clasificación entre amigos ni campañas verificadas. Para publicar en Google Play se necesitarán pruebas adicionales y una compilación de lanzamiento firmada.
